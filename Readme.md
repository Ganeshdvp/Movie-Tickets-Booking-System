# Movie Tickets Booking System (Python)

Note:- Developed by using python only! (No UI, No Backend, No Database...)
     - You can run through terminal.


## Requirements :- 
- Selecting Role ( admin or user )
- In Admin, can add movies, shows, tickets, Delete shows/movies, update shows/movies, view bookings and exit.
- In User, View Movies, Showtimes, Book tickets, View Booking and exit.
